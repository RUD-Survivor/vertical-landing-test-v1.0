# 体积云圆盘外缘：数值验证与修复

## 2026-10-11：历史响应与结构性修正

本节替代下文旧版的固定历史权重结论。此前外缘帧差与壳外漏云验证没有覆盖
历史响应，不能据此声称无拖影。新增 `--cloud-response` 不手动清除历史，先渲染
48 帧，再将低云密度归零（高云关闭）；同时读回原始云 L/T 和合成前后 HDR。
原版重建的总不透明度在第一帧、16/32/48 帧后分别残留 96.62%、48.86%、24.04%、
11.89%；全分辨率参考第一帧归零。残留先于最终 TAA 出现。

修正保留现有描述符、Bayer 轮转、四分之一尺寸 RT 和合成顺序：

- 新鲜内部样本直接替换历史，不再每 16 帧只接纳一半新结果。未采样像素检查
  当前 3×3 稀疏邻域的 L/T 和有限深度范围，不一致则补算本像素完整射线。
- 稀疏历史位移预算为 `0.25 / jitterPeriod` 像素/帧，按完整更新周期判断，
  超出预算即补算。原先按单帧 0.25 像素判断时，快速相机的参考误差达 0.06986，
  未通过 0.05 阈值；修正周期预算后降至 0.00262。
- 完整积分的外缘不使用稀疏点样本裁剪透射率；两者覆盖不同，曾导致移动外缘
  回归失败。外缘权重为 `clamp(max(1/16, 4*motionPixels), 0, 1)`，达到
  0.25 像素/帧即直接使用当前结果。恒速一阶估计器的解析延迟小于 0.25 像素，
  这是模型约束，并非任意体积、多层云或非刚体演化的无条件误差保证。
- 外缘使用像素方形与局部球壳轮廓的交面积，代替四条子射线的二值命中计数。
  用条件云散射/消光乘连续面积；角落薄片未命中子射线时补算面积重心射线。
  AirT RT 的 RGB 仍为大气透射率，alpha 存放几何面积；历史散射/消光按前后
  面积比重新归一化。相机出界时不会遗留整块云。独立面积参考计入引擎现有的
  0.5 km 径向大气相机偏移，不能拿未偏移几何原点直接验证面积。
- 主形状噪声以 `p + wind*time` 采样，所以历史材料点是 `p + wind*dt`。
  高云的球面平流和侵蚀的反向运动不能由这一单一速度完全描述，内部邻域检查
  与运动补采样继续兜底。风速/方向、云壳、行星中心、分辨率路径变化，以及
  时间倒退或跨越 0.25 秒时，拒绝原历史；低/高云密度与覆盖配置改变也作废历史。
  关闭后恢复与重分配仍走冷启动。因此响应测试的介质清空现在会自动触发失效，
  动态对照则持续保留历史，独立检验重投影和补采样。
- 屏幕像素使用一致的空间蓝噪声，Bayer 主采样和补采样共享积分抖动，静止时
  不再通过改变积分噪声制造帧间变化。它仍有空间积分误差，不能当作积分收敛证明。
- 代表云深度改为可见消光 `T*(1-Tstep)` 的加权中心，真空不参与深度与空气透视。
  云壳求交使用叉积冲击距离和 `(R-b)*(R+b)`，避免相机距离平方的大数相减。
  PerFrameData 尾部增加前帧相机坐标，CPU/GLSL 布局同步为 1904 字节；所有分配
  和绑定使用 sizeof，静态断言与完整构建核验布局。
- 空气透视的压缩 Mie 光谱改为在两个 LUT 端点重建后再求分段差，避免用几乎
  抵消的红色差值作分母。在 641×363、400 km 移动相机的失败像素，旧公式将
  当前亮度从约 0.37 放大到 55.625；新公式为 0.372314。此数值爆点曾造成
  亮度尖峰，不能靠更长历史过滤隐藏。端点差的各通道由输入端点辐亮度约束，
  独立消去误差测试检查有限值、能量上界和零长度恒等性。

`--cloud-diagnostic` 仅运行奇数尺寸的 400 km 移动场景，在关闭 God Ray 的
调试模式 99 中将当前亮度、历史亮度、位移写入不参与合成的 Fog RT RGB。
该模式只用于调查，跳过质量验收阈值，输出不得当成回归 PASS。

新增 `--cloud-dynamic` 含五组 64 帧场景：400 km 高度下相机每帧移动 2 km，
第 32 帧停止；默认 0.15 km/s 风动画；对应全分辨率参考；时间倒退和跳跃。
在第 31/32/48/63 帧比较约 5.6 万内部像素，排除参考没有子像素积分的外缘。
快速运动不透明度 RMS 最大 0.002622，停止后第 63 帧为 0.000510；风动画最大
0.000714。归一化辐亮度误差用 `(Ltest-Lref)/(1+max(Ltest,Lref))`，最大 RMS
为 0.003320。预设不透明度和辐亮度 RMS 阈值均为 0.05，未放宽；时间跳变必须
触发 cameraCut，覆盖范围外不能残留云，L/T 必须有限且 T 在 [0,1]。

GPU 日志位于 build/tests/cloud-structural-*.log。`--cloud-response` 断言第一帧
残留小于 1%，第 16 帧以后云散射与背景改变均为零。原有两种尺寸的外缘、前景
遮挡、冷启动回归继续沿用旧阈值。动态补采样有额外成本，性能需以 GPU 时间戳
衡量；这些 640×360/641×363 场景不能替代 1080p 实机场景的性能或视觉验收。
本次也没有新增真实日间水色标定。

最终验收（cloud-structural-*-final.log）：清空响应 192 帧、动态对照 320 帧、
640×360 与 641×363 外缘各 320 帧，以及原有 44 项 GPU 回归全部通过，Vulkan
验证错误为零。两种尺寸外缘面积最大绝对误差分别为 0.0008094、0.0008210；
稳定后最大呈现 RMS 分别为 0.0020103、0.0019240，最大单像素变化 0.083274、
0.086395，均低于保留的阈值。壳外残留和前景误覆盖为零。C++ 9 阶段、Python
36 项（含本文件对应的 12 项云测试）及强制完整 Release 构建通过。

GPU 时间戳测的是整个云系统（含 LUT、阴影和合成），排除各场景前 8 帧。
正常/奇数尺寸的静止默认路径中位数为 20.30/28.57 ms，400 km 移动为
31.49/26.42 ms；其余有云默认场景中位数约 18.88–29.26 ms。全分辨率单射线
直出静止参考为 10.80/7.49 ms，但不具备这里的外缘面积积分和历史重建。
真实变化区域补采样与外缘抗锯齿有成本；不能据此宣称 1080p 或 60 FPS 达标。
后续性能优化应保留当前响应、覆盖、动态参考与呈现阈值，不能恢复无条件历史复用。

以下保留前一次外缘修复的历史记录，数值与限制对应当时版本。

## 验证条件

使用生产 Vulkan 地形、独立海洋、大气、体积云、TAA 和交换链输出；设备为
NVIDIA GeForce RTX 4060 Laptop GPU。读回云 L/T、合成 HDR、实际呈现颜色。
固定太阳、时间和云风速，统一湿润地表用于排除岸线变化；移动相机每帧平移
0.1 km。原始基线与逐阶段记录保存在 build/tests/cloud-limb-*.log。

默认分辨率 640×360；奇数分辨率 641×363。十组场景各 32 帧：
关云、开启管线但云密度为零、默认四分之一分辨率静止、全分辨率直出、移动相机、1 m 近裁面、
第 16 帧切断云历史、近处前景、2000 km 宽视角、400 km 宽视角。
每组重新分配云历史，避免跨场景继承。

## 架构与根因

VkCloudSystem 按 raymarch → reconstruct → composite 顺序执行，随后进行场景
TAA 和唯一一次显示转换。原始四分之一分辨率路径使用 16 帧 Bayer 序列，
每个 4×4 像素块每帧只追踪一个像素。

1. 原始 reconstruct 把跨越云壳边界的点采样／双线性估计当成相邻像素的云。
   相机移动后，即使当前射线已经离开云壳，历史颜色仍可能保留。
2. 当前 Bayer 采样的云颜色绕过时间滤波，其余 15 个像素使用历史，导致
   空间估计和时间更新互相不一致。
3. 云代表位置经投影写成接近 1 的深度，再反投影作为历史锚点。小近裁面和
   轨道距离使薄云层共享少数深度值；无限远反投影还可能出现 w=0。
4. 首帧／历史重置用四分之一分辨率双线性填充。不同云柱混合的估计，在之后
   16 帧被各像素真实采样逐步替换，形成新的 4×4 亮度跳变。
5. 部分 4×4 像素块按向上取整后的纹理尺寸生成 UV，窗口尺寸不是 4 的倍数
   时，投影和重建像素中心不一致。
6. 无云像素（T=1）的云 AP 仍对已经完成大气合成的背景施加 L_air 和 T_air。
   在云代表距离变化时，背景被重复散射／衰减，即使云透射率不变也会闪烁。
7. 低轨宽视角下，云底内球切线改变追踪区间；只处理云顶外球会漏掉地球
   轮廓附近的 Bayer 不连续像素。

独立 CPU float/double 检查还测得原二次方程在切线附近的分类误差；包含
100000 km 远距相机时最大径向误差 38 m。该结果是 CPU 参考，不是 GPU
编译器逐指令误差证明。与本次像素足迹相比，它不是已复现大面积泄漏的主要
来源，因此没有修改整个大气系统的共享求交算法。

## 最终修复

- 云深度 RT 保持 R32F 格式和绑定布局，语义改为公里制射线距离；无命中为
  1e20。历史位置由相机位置、射线和距离直接重建；合成时才转换到场景深度。
  禁止把无命中哨兵与有效距离做线性插值。
- 由解析云壳的内、外边界和相邻像素的 impact-distance 导数确定边缘。边缘区域逐像素
  追踪，实际轮廓处增加 2×2 子像素光线，外围 Bayer 不连续带用单条光线。
  未覆盖云壳的像素禁止保留历史云；其输出为 L=0、T=1。边缘积分采用一个
  完整 Bayer 周期的历史权重（1/16），其余区域按原更新周期处理。
- 云 L/T 与空气透射率一起滤波。无历史／越界像素使用自己的射线冷启动，
  避免跨云柱双线性填充；滤波覆盖与代表距离保持一致。
- 云历史切断信号同步到最终场景 TAA。切断帧采用当前画面；恢复方差钳制的
  下一帧独立校验 HDR，之后再比较相同 resolve 模式下的呈现结果。
- Bayer 的 UV 使用真实全分辨率尺寸，末尾不完整像素块的坐标夹到有效范围。
- 三个云着色器使用 glslc -O；云 RT 增加 TRANSFER_SRC 供诊断读回。
  测试工具的 D32 staging 偏移按 4 字节对齐。
- 背景已有前景空气 B=Lf+Tf×Lb，插入云后应为
  Tc×B + Tf×Lc + (1-Tc)×Lf。云 AP 因而只衰减云散射，并补回被云遮住的
  前景空气；禁止对背景再次乘 Tf。CPU 独立分层推导和 GPU 空云逐像素恒等
  同时验证这条关系。

## 数值结果和验收范围

原始相同外缘区域（4084 像素）的固定相机第 31 帧：呈现线性亮度差 RMS
为 0.06314538，壳外超过一像素仍有 1445 个云透射像素。第一次距离／边缘
修复后，对应 RMS 为 0.00038876，壳外计数为 0。分别见
cloud-limb-baseline.log、cloud-limb-distance-edge.log。

最终测量区域同时包含地球表面和云壳外轮廓，取各自三像素足迹的邻域，
因此不能把区域大小不同的最终指标当作上述逐点配对结果。640×360 最终
第 18–31 帧的最大呈现 RMS：静止 0.00050879，10000 km 移动 0.00209152，
2000 km 移动 0.00184789，400 km 移动 0.00226529。全部壳外计数为 0。
前景 26896 个像素与合成前 HDR 逐通道比较，云导致的改写数为 0。
1 m／1 km 近裁面的静止云 T 指标一致到打印精度。
641×363 的对应最大呈现 RMS：静止 0.00041781，10000 km 移动 0.00172793，
2000 km 移动 0.00204106，400 km 移动 0.00212374。空云恒等两种分辨率各
32 帧、全部像素，云前／云后 HDR RGB 改写数均为 0。奇数分辨率前景有
27889 个像素，改写数也为 0。

检查所有读回值有限、T 在 [0,1]，并启用 Vulkan 验证层。
稳定模式下呈现 RMS 门限为 0.005，单像素亮度差门限为 0.12；该门限不是
“任何像素绝对不变化”的保证。移动云透射率使用静止 RMS 预算加相机每帧
像素位移的上界，避免把正常覆盖变化判为数值发散。切断帧及恢复 TAA 的
第一帧不与普通静止帧强行比较，但仍检查壳外覆盖、有限性和 HDR 稳定性。

性能没有按画面改善自动验收：本机 640×360 默认云路径各场景 GPU 中位耗时
约 18–23 ms，641×363 约 19–28 ms（包含云 LUT 更新、云影和合成）；
全分辨率直出参考约 11 ms。设备负载、时钟与温度会影响耗时，不能把两次
运行的不同中位耗时直接归因于分辨率。
边缘积分有额外成本，尚不能据此声称达到 60 FPS 或推断 720p／4K 性能。
全分辨率直出路径不执行此重建抗锯齿，保留随机积分闪点；它只作为数值对照，
没有通过默认路径的时间稳定性验收。动态天气、不同太阳角度、真实地表混合
岸线和长时间高速飞行不在此组冻结场景的验收范围内。

## 重现

运行 tools/build_ocean_gpu_validation.cmd 后：

```
build/tests/ocean_gpu_validation.exe --cloud-limb
build/tests/ocean_gpu_validation.exe --cloud-limb-odd
build/tests/ocean_gpu_validation.exe
```

--cloud-limb-baseline 关闭云缘阈值断言，用于调查；它使用当前着色器，并不
自动恢复旧版本。原始基线保存在独立日志中。

CPU 验证使用 tools/run_ocean_numerics.cmd 和
python -m unittest discover -s tests -p "test_*.py"。
正式完整构建使用 build_release.cmd force。

最终结果：两种分辨率各 320 帧、原有 44 项 GPU 回归通过，Vulkan 验证层
错误为 0；9 阶段 C++ 数值验证和当前仓库 25 项 Python 测试通过；全部
着色器及强制完整 Release 构建通过。详见 cloud-limb-final.log、
cloud-limb-odd-final.log、cloud-limb-regression.log、cloud-limb-cpu.log、
cloud-limb-python.log、cloud-limb-release.log。全分辨率直出参考不含重建
滤波，不能将它的有限值／覆盖检查通过误记为时间稳定性验收通过。
