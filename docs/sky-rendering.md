# Vulkan 星空使用与验证

## 使用

本文覆盖 Vulkan 飞行场景；旧 OpenGL 星空未迁移。
飞行场景默认使用日间相机曝光。受光地球前的星空较暗，只有少量较亮星点。
F5 星空面板中的“银河观测”将整个相机的最终曝光改为 128，日侧地球也会变亮。
`Radiance scale` 是线性光源乘数，不是另一套显示曝光；最终曝光、ACES 和 sRGB
转换仍由统一输出阶段完成。复位按钮恢复默认模式。

星表文件 `assets/data/sky-stars.bin` 必须随资产一起分发。它包含 HYG v4.1
中除太阳外、视星等不超过 6.5 的 8,920 颗恒星。来源、CC BY-SA 4.0 许可、
坐标约定和可复现生成方法见 [资源说明](../assets/data/README.md)。运行时不下载数据。
银河资源 `assets/data/milky-way.bin` 也必须分发。离线转换工具需要 numpy/OpenEXR，
游戏运行及普通构建不依赖 Python 或 EXR 库。

## 实现约定

- 银河全屏背景采样 NASA SVS 4851 的线性 HDR 全天球星表背景，替代高斯盘、
  核心及噪声。2048x1024 RGBA16F，12 级按球面面积加权的离线 mip，约 21.3 MiB。
  经度重复、纬度钳制；由连续方向导数驱动 textureGrad 和最多 16 倍各向异性过滤，
  避免 atan 接缝错误变粗。精确极点避免未定义的 atan(0,0)。
- 恒星用一个 32 字节/星的只读 SSBO、实例化四边形和加法混合绘制。位置与
  星等来自星表，通量遵循 `10^(-0.4*m)`。GPU 缓冲约 279 KiB，另有同大小 CPU 记录。
- 点扩散函数按像素积分；核心与宽核分别归一化，光晕是总能量的一个比例。
  `PSF sigma` 改变足迹而不改变总能量。用透视像素立体角将总通量转换为辐射亮度。
- 星空角投影跟随实际相机视场，去除视图平移，使用稳定近远平面求逆。
- 无几何深度的天空已进行空间过滤，输出时采用当前帧。重投影历史的插值和
  方差裁剪仍会改变点光源能量，因此不再依赖 TAA 隐藏星点混叠。地表与海洋
  的历史处理保留原有规则。清深度区域的大气/云也会采用当前帧，这是此策略的范围。
- 使用已有 `SkyboxPushConstants` 128 字节 ABI。背景绘制的矩阵为 inverse(VP)，
  恒星绘制为 VP；最后两个原填充标量传入视口尺寸。每次绘制分别推送完整常量。

恒星方向固定在 J2000 星表框架，未加入自行或岁差；框架北向目前映射世界 Y。
银河采用与亮星一致的 J2000 赤经/赤纬映射，默认艺术偏移为零。B-V 到 RGB 是近似色度模型，
缺失 B-V 使用 0.65。零星等通量 `2e-7` 和银河辐射尺度为相对标定；银河仍是
NASA 星表可视化，尚未使用绝对标定的全天球辐射资源。不得将当前结果称为天文测光验收。
天空变化无需重新生成星表；未来替换背景资源时应保留线性 HDR、像素积分和统一输出约定。

## 构建与复现

```powershell
$env:VULKAN_SDK='D:\Vulkan SDK'
.\build_release.cmd force
.\tools\build_sky_gpu_validation.cmd
.\build\tests\sky_gpu_validation.exe --sky-stage5
.\build\tests\sky_gpu_validation.exe --orbit
.\build\tests\sky_gpu_validation.exe
python -m unittest discover -s tests -p 'test_*.py'
.\tools\run_ocean_numerics.cmd
```

验证工具使用生产天空绘制、RGBA16F、生产最终输出及实际交换链读取。数值取自
原始 HDR；PPM/PNG 是实际显示码值，不使用另一套预览色调映射。
`--sky-stage1/2/3` 的编号用于命名和选择用例；它们不切换旧实现。
历史阶段截图和日志在每个实施阶段当时保存。

2026-10-11 第一轮历史结果（第五阶段已替换其中的程序银河）：

1. 亮度链路：4 个 GPU 用例；线性源缩放、零源及输出转换通过。
   原随机模型在高观测曝光下仍呈密集斑块，画面检查据此进入第二阶段。
2. 恒星成像：11 个 GPU 用例；跨 360p/720p、亚像素位置、PSF 尺寸、视场和
   离轴位置的单星通量最大误差 0.0814%；背向恒星为零。
3. 银河：18 个 GPU 用例；核心、反核心、南北银极、经度接缝及禁用边界通过。
   接缝两侧均值约 `5.12423e-6` / `5.12426e-6`。
   画面检查发现值噪声的平台形状后，改用梯度噪声并重新检查实际截图。
4. 最终：27 个 GPU 用例，包含连续旋转的 9 个单星帧；实际输出与当前帧参考
   最大误差 1/255。移动单星经 ACES 与 8 位输出后的积分显示亮度相位变化约
   2.76%（验收边界 5%），不宣称显示亮度严格不变。完整 Release 构建成功；24 项 Python 测试、9 个海洋 CPU
   数值阶段、44 项海洋 GPU 用例、64 帧太空海洋回归通过，Vulkan 错误为零。

FP16 暗值测试使用绝对次正规数误差与相对误差的联合边界；加法混合累计误差
按实际投影星点足迹重叠数限界，不用单一暗场均值比例替代逐通道检查。
星表二进制重建的 SHA256 与随仓库资产一致：
`969d40e7c12f281ee920645413dd9afed38dcce795de95b76fcee89255b37f5a`。

## 第五阶段：银河形态替换与验证

用户指出银河像塑料后，画面复查确认高斯带/核心与共用噪声产生规则发光条带。
此前数值通过不代表形态真实性验收。本阶段完全替换该模型，而非继续调噪声。
NASA 背景保留实际星群密度和暗区结构，亮星仍由独立 HYG 通量/PSF 绘制。
来源及转换见 [资源说明](../assets/data/README.md)；固定相对乘数 0.002，未做局部提亮。
原 Width/Dust/Core 控件移除，128 字节 GPU ABI 对应位置保留为填充。

最终 Release 构建成功，26 项 Python 测试、9 个海洋 CPU 阶段、35 个天空 GPU
用例、海洋 GPU 回归和 64 帧太空海洋回归通过；Vulkan 验证错误为零。
12 级 mip 的球面积分 RGB 相对基级最大变化 **0.0397%**。
线性源双倍缩放均值比 **2.00020884**，逐通道 FP16 误差限同时检查。
实际显示与 HDR 经 ACES/sRGB 的参考输出最大误差 **1/255**，所有天空测试无满码裁剪。
赤经接缝两侧均值 `1.94028002e-5` / `1.94023589e-5`，相对差约 **0.00227%**。
银心/反银心、南北银极、南北天极均覆盖；额外 1279x719 奇数尺寸使中心像素
精确对准天极，检验 atan(0,0) 防护及有限非负输出。
单星移动相位的积分显示亮度变化 **2.7587%**；这不是银河纹理的时间稳定性上界。
连续 10 帧预热、30 帧计时：1279x719、8,920 星，天空及屏障平均 **0.268 ms**。
显卡功耗/频率未锁定，该值不代表整帧性能或严格加速比。
